# 判断规则库 · analysis-rules

这里存放的是从长期实践中被反复验证、甚至被反复推翻后重建的判断规则。复盘与分析时直接套用。每条规则都写明「为什么」，避免机械执行。

## 一、目标决定判据（最高原则）

同一份数据，在不同目标下结论完全不同。先看档案里的目标，再选判据：

| 用户目标 | 主要判据 | 不看的 |
|:--|:--|:--|
| 减脂 | 体脂趋势 / 腰围 / 体重趋势（同条件对比） | 单周波动；训练容量是否增长 |
| 增肌 | 训练表现趋势（重量 / 次数 / 质量） / 围度 | 体重短期下降（糖原水分波动正常） |
| 体成分重组 | 体脂趋势 + 瘦体重 / 训练表现双线 | 单一指标的短期波动 |
| 体能 / 运动表现 | 专项指标（距离 / 等级 / 完成度） | 体重体脂（除非用户自己关心） |
| 保持健康 | 出勤规律性 / 体感 | 几乎所有数字类 KPI |

**默认目标未定时的口径**：只描述事实与趋势，不给「达标 / 未达标」判断。

## 二、负荷推进判据（默认口径：不追力量）

除非用户在建档时明确「以力量增长为目标」，否则：

- ⛔ 禁止把「没加重」写成问题或缺口，不追问为什么不加重，不催加重
- ✅ 成绩单换成三条：**重量守住没有（不掉即胜）/ 动作质量或连续性有没有提升 / 有没有疼痛**——三条优先于任何重量数字
- 🎯 加重的定位是可选工具，只在两种情形出现且由用户当场决定：某组做完还能轻松多做 5 次以上（说明选轻了，可纠偏）；或状态特别好且用户自己想试。试不上去立刻退回，退回不算失败
- 📌 「停滞」的重新定义：**重量 / 次数 / 动作质量三者至少有一样在动就不算停滞**。重量不动但次数更多、或动作更干净，同样是进步。三者全停且体感轻松，才值得在复盘里提一句
- ⚠️ 术语澄清：用户常把「加重量」说成「提高容量」。容量 = 重量 × 次数 × 组数。听到「提高容量」先问清是加重量还是加组数

## 三、训练频率：不是瓶颈

- 「一周去几次」不是有意义的口径；有意义的是「一个肌群一周被刺激几次」
- 频率低不自动构成问题——判据是：当前频率下目标是否在推进（脂肪在降 / 表现在涨）。推进中就不动它
- 值得提醒的反向风险：频率过低会导致单次塞太多内容、后段质量崩塌、新动作永远排不进去——这是效率问题，不是纪律问题
- 中断训练（有事 / 疲惫 / 假期）属正常波动，不当成纪律问题。长假停训就写「长假停训，无记录」，一句带过，不虚构、不追问

## 四、数据可比性规则（分析错误的第一大来源）

1. **单位**：同一动作的历史记录若单位体系不同（kg / lbs / 器械配重格），**不可直接对比**。先确认口径，再比较
2. **单侧 vs 双侧**：单侧动作重量约为双侧一半、次数约为两倍。「重量轻 + 次数翻倍」是单侧模式正常特征，不是退步。口径不同的两条记录不可比
3. **「重量轻 + 次数翻倍」辨模式，再看档位**：单侧记录的重量减半、次数通常是双侧的约 2 倍——见到这种形态先按单侧理解，不要判成负荷过轻
4. **测量条件**：体重只做同条件对比（空腹 vs 餐后、晨起 vs 晚间）。不同条件的点可比性差，图表里要分开或标注
5. **体脂秤绝对值**：家用体脂秤的单点读数误差大，**趋势与幅度可信、绝对值存疑**；换秤 / 换电池后的跳变要在图上标注
6. **合理性兜底**：任何数字先过一遍常识——「按这个单位读会是世界级水平」→ 几乎可以肯定是单位或记录错误，向用户确认后再用
7. **同场次同类器械单位应一致**：不一致就是记错的强信号，先校验再落盘

## 五、数据缺失的处理

- ⭐ **「文档里没记录」≠「用户没测」**：判断任何维度「长期空白」之前，**必须先显式问用户一次**「这段时间有没有测过」。用户通常手里有数据，只是没主动交。下结论前问这一句，能避免最严重的分析事故
- 缺数据标「未追踪」，显式写出来——不忽略、不留白、不脑补
- 对比用「本次 vs 上一个可对比点」，不强行对齐周期末日值
- 同周期有多个数据点时，看「均值 vs 均值」而不是首末单点（单点波动可达很大幅度）
- 异常值（比同类记录低一个数量级之类）先怀疑记录不完整，再分析训练本身

## 六、减脂速率安全线（目标含减脂时适用）

- 可持续上限：**每周减重 ≤ 体重的 1%**。接近上限时要检查瘦体重（或力量表现）是否在掉
- 掉肌肉的信号：力量表现连续两次下滑 / 瘦体重连续两次下降 → 优先处理：放宽缺口，先保肌再谈速率
- 长假后体重跳升先别慌：涨的相当一部分是糖原 + 水 + 肠道内容物，恢复训练后 2-4 周自然回落，不触发任何止损
- 短期波动 ±1kg 级别没有信息量，别为它调整任何东西

## 七、睡眠相关（维度开关已开时适用）

复盘睡眠时常见两个流传很广但错误的归因，直接纠正：

- **「练完皮质醇高所以睡不着」不成立**：皮质醇半衰期 60-90 分钟，训练后 2-3 小时基本回落。晚训影响入睡的主因是**核心体温升高（回落需 2-3 小时，最被低估）+ 交感神经唤醒**。有效解法是拉开训练与就寝间隔（≥2.5 小时理想 3 小时）、训后 30-60 分钟洗温水澡（出浴后散热加快）、呼吸放松法——而不是「降皮质醇」
- **「快速激发疲劳感助眠」这条路走不通**：困意只能靠累积睡眠压力（固定起床时间是最强单一杠杆）+ 降低入睡门槛。睡前剧烈运动、睡前喝酒「助眠」都是反效果（酒精砍深睡）
- 睡眠数据里，**主观清醒度比时长更能反映质量**；有手表数据时深睡占比只做趋势参考

## 八、疼痛分级红线（优先级高于一切）

| 信号 | 处置 |
|:--|:--|
| 肌肉酸胀 | 正常，继续 |
| 关节 / 肌腱酸胀发紧 | 做完当前组即止，下次不加重，观察 |
| 尖锐刺痛（当场） | 立即停，当天不再练该部位 |
| 发麻 / 神经信号 | 立即放弃该动作，记录在案 |
| 隐痛持续 24h+ | 减量 50%；72h 不消退建议就医 |

任何情况下不建议靠忍痛、借力、动作变形完成训练。涉及持续性疼痛、疑似伤病，一律建议就医——技能做记录与提醒，不做诊断。

## 九、其他经验规则

- **排在最后的动作永远长不起来**：单次训练的资源被前面的动作吃光，末位动作（通常是弱势部位专项）会系统性缺席。解法是任务化（固定哪天、几组、做完打勾），只调顺序没用
- **周末 / 聚餐 / 应酬是饮食管理的最弱一环**（有此场景的用户）：管理重点不在日常，在高热量单次场景。两条底线——不空腹饮酒 + 记量。日常小酌若实测不阻断目标进展，就不要管它
- **「计划应该是什么」不重要**：用户主动取舍（换动作、减组数、跳过某环节）只要逻辑自洽就是合理策略，复盘时评价「这个取舍的代价与收益」，而不是评价「没按计划执行」
- **评价里少用绝对化措辞**：「本周容量回落 20%」这类结论，先过一遍数据可比性与记录完整性检查（第四、五节）再写

## 十、事件驱动检测（低频原生适配，全部按发生次数计算）

以下检测不依赖日历节律，数据稀疏照常可用。**所有判定数字由脚本计算**（SKILL.md 算术铁律），以下规则定义判定逻辑。

### 10.1 PR 检测（口径安全版）

- **前置校验一票否决**：候选记录与历史记录必须通过可比性检查（第四节）——单位一致、单双侧口径一致、测量条件一致——才允许进入 PR 比较。口径存疑时宁可漏判，不误判
- **PR 定义**：同一动作同口径下的历史最大工作重量（不是 1RM 估算；1RM 涉及公式假设，只做参考不进 PR）
- **报法**：「卧推 70kg，超过今年 8 月的 65kg，新高 ⭐」——带历史值和时间，用户能看见跨度
- 懒用户价值：记录越稀疏，用户越记不住自己的历史最佳，PR 检测在低频场景下反而更有用

### 10.2 平台期检测（提示，不催）

- **定义**：同一动作同口径、**连续 ≥3 次记录**重量与次数完全相同，且用户体感不轻松（三项同时满足才提示）
- **提示措辞**：只陈述事实「这个动作连续三次都是同一重量同一次数了」，是否调整由用户决定
- ⛔ 与「不追力量默认」的边界：用户目标非力量时，这条检测**默认关闭**（档案里记）；重量同值在减脂期是正常且被接受的状态，此时平台期检测只看动作质量与体感维度

### 10.3 趋势方法随数据密度自适应

| 数据密度 | 趋势方法 | 表述口径 |
|:--|:--|:--|
| 密（约 ≥2 个点/周，且区间 ≥4 周） | 区间均值对比（前半段均值 vs 后半段均值） | 「区间内均值从 X 到 Y」 |
| 中（约 1 点/周） | 首末点对比 + 中间点走势描述 | 「从 X 到 Y，中间在 Z 附近徘徊」 |
| 稀（间隔 ≥2 周或总点数 <4） | 点对点 + 方向判断，不计算速率 | 「数据点少，只谈方向：在降」 |

- 速率类结论（每周降多少）**只在「密」档允许出现**——稀疏数据算出的速率是噪声
- 图表呈现时在图上标注当前密度档位（visualization.md）

### 10.4 单点异常检查（与频率无关，每次记录都做）

- 体重单点相对前一可比点跳变超过 **±2.5%**（或 ±1.5kg 取大者）→ 记录时顺口问一句测量条件（空腹？餐后？换秤了？），notes 里记下条件再定性质，不直接当真实变化
- 单次训练的消耗 / 容量比同类记录**低一个数量级** → 先怀疑记录不完整（漏记动作、APP 没关），再谈训练质量

### 10.5 交叉验证（判断信号好坏，不依赖日日数据）

- 体重降 + 力量表现守住或上涨 → 体成分改善方向，好信号
- 体重不变 + 围度 / 体感变好 → 可能是重组，不是「没效果」
- 体重降 + 力量连续下滑 → 减脂速率可能过头，见第六节安全线
- 体重跳升 + 训练恢复后回落 → 糖原与水分波动，不是脂肪反弹
